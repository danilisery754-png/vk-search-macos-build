# Изменения v0.4.0

## Интерфейс и масштабирование

- Основное окно переведено на bounded-layout: растущие списки больше не выталкивают критические элементы за нижнюю границу приложения.
- Добавлены аккуратные внутренние scroll-контейнеры и единый стиль полос прокрутки.
- В «Настройки → Сообщения» первый вариант текста остаётся крупным, дополнительные варианты компактные; искусственного лимита количества вариантов нет.
- Экран аккаунтов упрощён до аватарки, имени, VK ID, включения и заметки; техническая статистика убрана из постоянной карточки.
- Кнопка `⋮` аккаунта теперь открывает рабочее меню: включить/выключить, изменить заметку, открыть сообщения, обновить вход, удалить аккаунт.
- Сетка аккаунтов рассчитана на 100+ аккаунтов и прокручивается внутри своей области.

## Сообщения

- При открытии диалога история синхронизируется автоматически; ручная кнопка обновления остаётся резервной.
- Первично загружается до 300 последних сообщений, более старые сообщения догружаются вверх порциями без скачка текущей позиции.
- Шапка диалога и поле отправки закреплены; история прокручивается независимо.
- В шапке показано «Вы отвечаете от:» с заметкой/именем и аватаркой конкретного VK-аккаунта.
- Если пользователь читает старую часть переписки, новые сообщения не принудительно прокручивают его вниз; появляется кнопка «↓ Новые сообщения».
- Диалоги, в которые VK запрещает отвечать, сохраняют доступную историю и показывают понятное состояние вместо composer-поля.
- Списки «Все / Непрочитанные / Прочитанные» используют стабильный независимый скролл.

## История запусков и результаты

- «Успешно написали» и «Не удалось написать» по-прежнему физически разделены, но теперь каждый результат жёстко привязан к конкретному запуску.
- Новый запуск не смешивается со старыми результатами.
- Добавлен селектор «Запуски» с бессрочной историей, счётчиками и статусами.
- Архивный запуск можно открыть одновременно на обоих экранах результатов; выбранный запуск сохраняется между переходами.
- Экспорт TXT/CSV/XLSX и копирование работают только по выбранному запуску.
- Старый запуск можно удалить вручную после подтверждения; текущий запуск защищён от удаления.
- Для каждого запуска сохраняется исходное количество групп (`original_count`).

## Данные и совместимость

- Добавлены только data-preserving Alembic-миграции: состояние возможности ответа в диалогах и исходный размер запуска.
- Реальные границы старых запусков v0.3.5 сохраняются через существующий `WorkItem.run_id`; старые результаты не объединяются искусственно.
- Добавлен regression-тест обновления базы v0.3.5 → v0.4.0 с сохранением аккаунта, зашифрованного токена, browser profile, настроек, диалогов, сообщений и результатов.

## Защищённая авторизация

- Рабочий VK authorization/token-refresh flow из v0.3.5 не переписывался.
- `backend/app/vk/auth.py` не изменён в рамках v0.4.0.
