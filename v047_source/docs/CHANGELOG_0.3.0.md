# Изменения v0.3.0

## Исправлено

- Windows-сборка больше не использует системный Python, `py.exe`, `PATH`, `PYTHONHOME` или `PYTHONPATH`.
- Обычный Python installer заменён официальным переносимым NuGet CPython 3.13.15.
- Устранён сбой Windows PowerShell 5.1 на кириллице: PS1 и Inno Setup сохранены с UTF-8 BOM.
- Устранено ложное продолжение после ошибок нативных команд: каждый этап проверяет exit code.
- После «Остановить» сохранённый проход можно снова запустить без потери групп.
- Задачи отключённого аккаунта при продолжении возвращаются в общий пул.
- Экспорт теперь содержит отдельную колонку «Куда получилось».

## Добавлено

- Диагностика аккаунта: auth/API/session/work, назначено, последнее действие и ошибка.
- Ручное создание и список резервных копий в настройках.
- Полная история группы с попытками, причинами, VK object ID и техническими событиями.
- TXT export из обоих экранов результатов.
- Сортировка и изменение ширины колонок результатов.
- Фильтр статусов и сортировка общего списка групп.
- Сворачиваемые секции аккаунтов в едином inbox.
- Раскрываемые технические данные в логах.
- Глобальный поиск, статус работы и счётчик непрочитанных в верхней панели.
- Матрица покрытия мастер-промпта.

## Проверено автоматически

- 63 backend unit/integration/contract tests;
- TypeScript typecheck и Vite production build;
- desktop source `--self-test` на чистой временной БД;
- UTF-8 BOM и контракт полностью изолированной Windows-сборки.

Фактический EXE и живые VK-методы требуют Windows 10/11 и входа тестового VK-аккаунта; эти проверки намеренно не подменяются моками.
