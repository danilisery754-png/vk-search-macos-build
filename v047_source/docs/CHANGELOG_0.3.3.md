# Изменения v0.3.3

- Исправлен HTTP 500 при запуске браузерной авторизации и окна сообщений: FastAPI routes теперь выполняются в активном asyncio loop.
- Авторизация сначала пробует системный Edge, затем встроенный Chromium; диагностическая ошибка не раскрывает token или OAuth URL.
- Добавлен общий неограниченный список вариантов текста. Для каждой группы выбирается один стабильный вариант и без изменений используется и в ЛС, и в предложенной записи.
- ЛС и предложка пробуются независимо и последовательно: недоступность одного способа не блокирует второй.
- Старые раздельные тексты автоматически объединяются без потери и дубликатов.
- Настройки переведены на кнопочные вкладки без hash-scroll; добавлена отсутствовавшая вкладка «Дополнительно».
- Исправлено переполнение подписей карточек главного экрана в узком окне.
- Windows-сборка дважды запускает application self-test и дважды browser self-test уже замороженного EXE до упаковки.
- Установщик больше не блокируется на сетевом WebView2 bootstrapper: проверка/установка компонента остаётся под ограниченным таймаутом первого запуска приложения.
- Добавлены backend и frontend regression tests для всех перечисленных исправлений.
