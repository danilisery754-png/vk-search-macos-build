# Матрица приёмки

## Автоматически в репозитории

- нормализация грязного ввода и dedupe;
- 4 аккаунта × 50 групп = 200;
- баланс 120 → 30/30/30/30;
- атомарный claim двумя потоками;
- lease recovery → reconcile, а не слепая отправка;
- уникальный idempotency key;
- частичный успех и полный результат;
- bounded retry и неоднозначный network result;
- две независимые выборки результатов;
- чистые ссылки и TXT/TSV/CSV/XLSX с отдельной колонкой назначения;
- шифрование/identity mismatch/single-flight авторизации;
- изоляция одинакового peer между аккаунтами;
- ответ токеном владельца диалога;
- `in_read`/`out_read` и `messages.markAsRead`;
- фоновая синхронизация без активного запуска рассылки;
- сохранённый browser profile и single-flight окна сообщений;
- автономный `--self-test` desktop entrypoint;
- FastAPI smoke и миграция на чистой БД;
- TypeScript typecheck и Vite production build.
- восстановление остановленного прохода и перераспределение отключённого аккаунта;
- диагностика аккаунтов, ручные backup и полная история группы;
- полностью изолированный NuGet Python для Windows-сборки.
- HTTP 202 авторизации и открытия сообщений из реального asyncio loop;
- Edge-first/Chromium fallback без утечки URL или токена в ошибке;
- один стабильный вариант общего текста одновременно для ЛС и предложки;
- 250 вариантов текста, отсутствие фиксированного лимита и валидация пустых значений;
- вкладки настроек без hash-scroll и адаптивные подписи карточек.

## Windows 10 x64

Минимальная цель: build 17763 (1809/LTSC 2019).

1. Установка без Python/Node/PyCharm.
2. Первый запуск и WebView2.
3. Edge auth, 2FA, captcha.
4. Chromium fallback.
5. Перезапуск и сохранение профиля.
6. Принудительное завершение во время очереди.
7. Продолжение без дубля.
8. Tray и выход.
9. Portable zip.
