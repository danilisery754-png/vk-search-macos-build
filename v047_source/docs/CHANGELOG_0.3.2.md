# Изменения v0.3.2

## Исправлено

- Устранено падение готового GUI EXE с `AttributeError: 'NoneType' object has no attribute 'isatty'`.
- Self-test и обычный запуск приложения теперь используют один фабричный путь Uvicorn без консольного formatter.
- Исправление действует не только на проверочный режим, но и на обычное открытие приложения.

## Проверено

- Добавлен регрессионный тест, который обнуляет `sys.stdout` и `sys.stderr`, как это делает PyInstaller `console=False`, и запускает реальный локальный сервер, миграцию базы и HTTP-проверку.
- Полный набор: 68 backend tests, production frontend build, compileall, dependency check и чистая распаковка релиза.

Присланный Windows-журнал подтверждает успешное создание PyInstaller EXE до запуска self-test. Сам бинарник v0.3.2 требует новой Windows-сборки, потому что исправление находится внутри замороженного Python-кода EXE.
