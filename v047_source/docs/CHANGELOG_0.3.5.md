# Изменения v0.3.5

## Авторизация VK

- Возвращён проверенный VKHost-сценарий из рабочего проекта: обычный `vk.com` для входа → кнопка «Я вошёл в VK» → VKHost → точный `vk.com` → подтверждения VK → автоматический захват `access_token`.
- Кнопка `Продолжить как <имя>` ищется по реальному префиксу, а не по ошибочному точному тексту `Продолжить`.
- Поддержано окно `Этот номер ещё ваш?` с точным нажатием `Да`.
- Токен ловится не только из `page.url`, но и из событий навигации, frame URL, реального `window.location.href` и Chrome DevTools target list. Это закрывает гонку, когда токен уже виден в адресной строке, а Playwright ещё показывает старый URL.
- Если первый пойманный токен уже отклонён VK, получение повторяется один раз автоматически в той же сохранённой сессии.
- Если рабочий токен истёк позже, VK-операция один раз пытается автоматически получить новый токен из сохранённого профиля и повторить исходный API-запрос. Если сессия требует пароль/2FA/CAPTCHA, аккаунт переводится в `requires_login` без бесконечных повторов.
- Автоматическое обновление токена подключено к рассылке, предложке, импорту/резолву сообществ и inbox-операциям.

## Проверки

Добавлены регрессии для `Продолжить как…`, чтения токена из видимой адресной строки, navigation-event и CDP fallback, окна подтверждения номера, explicit `Я вошёл`, повторного получения отклонённого токена и автоматического refresh при последующих VK API вызовах.
