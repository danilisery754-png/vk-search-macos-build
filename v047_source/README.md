# VK Outreach Manager

Отдельное локальное приложение Windows для одного оператора и множества независимых VK-аккаунтов. Общий список сообществ распределяется автоматически; ЛС и предложенные записи обрабатываются отдельно; результаты находятся на двух разных экранах; ответы собираются в единый inbox.

## Что реализовано

- отдельное окно Windows, системный трей и защита от второго запуска;
- Windows 10 x64 build 17763+ и Windows 11 x64;
- встроенный Python 3.13.15 в release-сборке — Python/PyCharm пользователю не нужен;
- авторизация через отдельный Edge/Chromium profile, автоматический захват и `users.get` validation;
- Windows DPAPI для токенов, маскирование секретов в логах;
- несколько аккаунтов, заметки, независимые токены, profiles и inbox;
- компактные карточки аккаунтов с рабочим меню действий и масштабированием на 100+ аккаунтов;
- грязный импорт ссылок/ID, нормализация и dedupe;
- лимит отдельно на каждый аккаунт, случайное сбалансированное распределение;
- SQLite WAL, Alembic, foreign keys, индексы и короткие транзакции;
- atomic claim, leases, attempt journal, deterministic `random_id`, crash recovery;
- для каждой группы один и тот же выбранный текст последовательно отправляется и в ЛС, и в предложку, если доступны оба способа;
- неограниченный удобный список вариантов общего текста вместо двух раздельных полей;
- `messages.send` и `wall.post` за отдельным VK adapter;
- ограниченные retry; неоднозначный ответ после сети уходит в сверку, а не слепой дубль;
- две физически раздельные таблицы «Успешно написали» и «Не удалось написать» с бессрочной историей по запускам;
- TXT/TSV/CSV/XLSX, выбранные строки и чистые списки ссылок;
- единый inbox с автоматической загрузкой диалога, пагинацией истории и жёсткой привязкой ответа к аккаунту;
- фоновая синхронизация диалогов и непрочитанных сообщений независимо от запуска рассылки;
- точные маркеры `in_read`/`out_read`, отметка прочтения через VK API и открытие сообщений в сохранённом профиле;
- современный русскоязычный React UI и виртуализация больших результатов;
- сортировка, фильтры, выбор строк, изменение ширины колонок и подробная история каждой группы;
- автоматические и ручные резервные копии с ограниченным хранением.

## Готовая Windows-сборка

Релиз собирается на Windows двойным щелчком по файлу:

```text
build\СОБРАТЬ_WINDOWS.cmd
```

После успешной проверки EXE сценарий сам откроет папку `build\release`. Запускать от администратора не требуется.

Скрипт сам:

1. скачивает официальный переносимый Python 3.13.15 из NuGet в папку `build`;
2. игнорирует любой установленный в Windows Python и очищает его переменные окружения;
3. создаёт чистое окружение и устанавливает фиксированные зависимости;
4. использует уже подготовленную production-сборку React — Node.js не нужен;
5. загружает запасной Chromium и WebView2 bootstrapper;
6. автоматически устанавливает Inno Setup, если его нет;
7. дважды запускает автономный `--self-test` уже собранного EXE;
8. дважды проверяет запуск встроенного Chromium из собранного EXE;
9. создаёт portable zip и полноценный установщик.

Результаты находятся в `build\release`:

- `VK_Outreach_Manager_Setup_0.4.0.exe`;
- `VK_Outreach_Manager_Portable_0.4.0.zip`.

На пользовательском компьютере Python, Node.js и PyCharm не нужны.

## Разработка и тесты

Backend:

```text
python -m venv .venv
.venv\Scripts\python -m pip install -e "backend[dev]"
cd backend
..\.venv\Scripts\python -m pytest
```

Frontend:

```text
cd frontend
npm ci
npm run build
```

## Важный LIVE-статус

Автоматические тесты доказывают внутреннюю логику и контракты, но не заменяют реальную проверку VK. Перед рабочей рассылкой пройти `docs/VK_LIVE_REGISTRY.md` на тестовых аккаунтах. Приложение специально не маскирует непроверенную возможность догадкой: неизвестные ответы остаются в диагностируемом состоянии.

## Данные

По умолчанию Windows хранит базу, browser profiles, логи и экспорт в:

```text
%LOCALAPPDATA%\VK Outreach Manager
```

Удаление аккаунта физически удаляет его токен и отдельный browser profile. История обработанных групп остаётся связанной через сохранённый снимок заметки аккаунта.
